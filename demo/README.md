# PhishGuard demo

Static, in-browser version of [PhishGuard](https://github.com/WasimSheikh/phishguard). The weights in `model.json` come from `scripts/export_weights.py` and the feature code in `phishguard.js` is a port of `phishguard/features.py`. A learning project, not a security product.
